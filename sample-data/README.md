# Sample data — SYNTHETIC

**Everything in this folder is synthetic and illustrative.** All organisations, people, email addresses and activity histories are invented. Every organisation name ends in "(synthetic)". Domains use the reserved `example.org` TLD. Phone numbers use the UK Ofcom range reserved for drama (`+44 7700 900xxx`). None of it describes a real organisation, person or outcome, and the funnel rates it produces are not benchmarks.

The files are generated by `scripts/generate-sample-data.mjs`, a seeded mulberry32 PRNG with default seed `20261016`. Run `npm run generate` to regenerate them. The same seed always produces byte-identical files, and `tests/sample-data.test.js` checks this.

## Deliberate data-quality issues

These are planted so the checks and tools have something to find:

- **Organisation duplicates (6).** Each is a spelling variant of an existing organisation:
  - `Univ. of …` with `www.` on the domain
  - `The …` with a different domain
  - an upper-case name with an `https://…/contact-us` domain
  - an exact name with a blank domain
  - an exact name with the same domain
  - a different department name with an upper-case domain
- **Contact duplicates (3):**
  - two with the same email in different case
  - one with the same name at the same organisation
- **Emails:** 5 missing, 5 malformed, and 4 with stray spaces or capitals
- **Organisation names and domains:**
  - 2 organisation names with extra whitespace
  - 2 domains written as a URL or in upper case
- **Leads:**
  - 6 open leads with no follow-up date, plus 2 with `DD/MM/YYYY` dates
  - 2 open leads with no owner
  - 1 "Not contacted" lead that has an email logged

## Import CSV columns (prospects)

`organisation_name` (required), `organisation_type` (University, School, Hospital, NGO, Council, Other), `domain`, `region`, `contact_first_name`, `contact_last_name`, `contact_title`, `contact_email`, `contact_phone`, `stage` (key or label, e.g. `qualified` or `Qualified interest`), `lost_from_stage`, `priority` (high/medium/low), `owner`, `next_action`, `follow_up_date` (YYYY-MM-DD; DD/MM/YYYY converted), `notes`.

The app's leads export uses the same columns plus `opportunity_id`, `follow_up_status`, `last_activity`, `activity_count` and `data_quality_issues`. You can import an exported file again.
